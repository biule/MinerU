怎么用

  1. 用浏览器打开课程 HTML（可以直接双击文件）；所有页面离线可读，不依赖 CDN。
  2. 先读“知识”部分，再完成检索练习（quiz）。答错会立即显示解释。
  3. 完成“源码练习”或“动手挑战”后，再进入下一课。不要跳课；08–09 依赖前七课。
  4. 参考文档用于复习和速查；它们可以打印。
  5. 任何不清楚的地方，直接问你的教师（agent）——贴出代码行、命令输出或题目即可。
