PDF 流水线：窗口内的阶段与回退

这节课只做一件事：能按顺序说出一个 PDF 窗口内部发生了什么——布局、原生文本、表格、公式、OCR、VLM、印章、裁图——并解释每个阶段的启用条件。

为什么学这个：解析质量问题的根因几乎都在这些阶段的顺序与回退规则里。改流水线之前，必须先知道现在是什么顺序、为什么。

1. 窗口

  • PDF 按窗口处理，默认 64 页，可用 MINERU_PROCESSING_WINDOW_SIZE 调整。
  • 窗口之间共享同一个 PDFDocument 与模型实例；页面图像与临时数组按窗口释放。
  • 准备/收尾持有本地模型锁；VLM 推理期间释放锁，让其他文档可以使用小模型。

2. 阶段顺序

窗口准备渲染页面图 → 小模型 layout → 表格方向检测 → 原生表格优先
推理（按档位分叉）flash：OCR；medium：MFR/表格/OCR；high/xhigh：VLM 抽取 + 行内切片识别
正文回填PDF 文本层优先 → OCR 补齐 → 行级元数据 → 公式编号合并
收尾印章 OCR（medium/high）→ 视觉块裁图 → 释放窗口资源

3. 布局分析

  • 模型：PP-DocLayoutV2（Torch 或 ONNX），一次处理整窗。
  • 输出每块的 label、bbox、score；label 与内部块类型的映射是显式表（VLM_LAYOUT_LABEL_MAP）。
  • layout 结果还要经过标题拆分、表格方向检测、原生表格优先，才会成为最终块。

4. 原生文本 vs OCR

# backend/analysis/pdf/text/content.py —— txt 模式优先用 PDF 文本层
try:
    page_char_count = pdf_page.get_char_count()
except Exception:
    page_char_count = None

# 页面字符数不超阈值才尝试原生文本；扫描件退回 OCR
if not isinstance(page_char_count, int) or page_char_count <= MAX_NATIVE_TEXT_CHARS_PER_PAGE:
    evidence = prepare_text_evidence(
        pdf_page,
        excluded_script_regions=inline_math_regions,   # 行内公式区域排除
        table_regions=table_regions,                   # 表格区域排除
    )
  • 同一区域不会同时被“文本层 + 公式/表格”重复消费。
  • 文本证据支持快照缓存（PageSnapshotCache），同页在布局与正文阶段复用，随后逐页释放。

5. OCR 与公式的启用矩阵

# backend/analysis/pdf/ocr.py —— 由 parse_mode 与 effort 决定
def _build_ocr_det_type_and_mfr_enable(parse_mode, effort):
    if effort == "medium":
        return PIPELINE_DET_TYPE, True      # basic：跑完整 MFR
    if parse_mode == "txt":
        return VLM_TXT_DET_TYPE, False      # standard/advanced 文本模式：只补检测
    return VLM_OCR_DET_TYPE, False          # standard/advanced ocr 模式：VLM 识别正文

6. 行内公式的 VLM 切片与回退

Standard/Advanced 的文本模式中，表外行内公式切片交给 VLM 文本识别（batch_recognize_text）；失败处理有严格分级：

# model/vlm/text_recognition.py —— 不是所有错误都允许降级
def raise_unrecoverable_text_error(error: Exception) -> None:
    # 取消、引擎死亡、程序契约错误必须传播，不能降级成单片识别失败
    if (is_fatal_engine_error(error) or isinstance(error, (
        ClientClosedError, MemoryError, AssertionError, AttributeError,
        TypeError, LookupError, NotImplementedError,
    )) or (isinstance(error, RuntimeError) and not isinstance(error, ServerError))):
        raise error
  • 单片失败/空内容/定界符残缺：仅该片回退 MFR，并记录告警。
  • 取消、引擎死亡、契约错误：直接抛出，不静默降级。
  • 可恢复的批量异常：逐片补试一次，保留已成功结果。
回退原则：“局部失败局部回退，全局失败全局报错”。回退仍无有效结果时报告错误。

7. 其余阶段

  • 印章：medium/high 用独立印章 OCR 模型；xhigh 由 VLM 结果补图片容器。
  • 视觉素材：_attach_visual_block_images 按块 bbox 裁剪页面图挂到 image/table/chart/equation 块。
  • 公式编号：编号块合并进相邻公式块（optimize_hybrid_formula_number_blocks），保证裁图包含编号区域。
  • 表格：basic 走“分类 → 无线批量 → 有线单表”；standard/advanced 文本模式先尝试 PDF 原生表格，复杂表回退模型。
