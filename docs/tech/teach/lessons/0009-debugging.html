Lesson 09 · 综合

排障手册：错误码 → 根因 → 动作

这节课只做一件事：给定一个错误码或现象，能定位到阶段、读对日志、给出正确修复。这是检验前八课是否真正内化的实战关。

1. 错误码矩阵

错误码内部类型 / HTTP根因动作
server_not_runningapi_error / 500Doclib 未启动mineru server start
quality_tier_unavailableengine_error / 503无 basic/standard 引擎启动本地 parse-server / --remote / 显式 flash
no_engineengine_error / 503本地 parse-server 禁用config set parse_server.local.mode managed
tier_mismatchinvalid_request_error / 400服务不支持该档位查 /v1/tiers / server status --json
tier_unsupported_for_file_typeinvalid_request_error / 400对原生格式请求质量档位用 flash
file_type_unsupportedinvalid_request_error / 400扩展名不在边界内转格式或扩展 DocVortex
page_range_invalidinvalid_request_error / 400非 PDF 页范围 / 语法错用 1-5、r1、all
parse_wait_timeouttimeout_error / 408等待超时（解析仍在进行）增大 --wait 或稍后 read 缓存
remote_timeout / remote_unreachableapi_error / 503远端不可达查网络/URL/Key；或回本地
invalid_api_keyauthentication_error / 401远端或自托管 Key 错误更新 parse_server.*.api_key
parse_server_dependency_missinginvalid_request_error / 400档位依赖未安装mineru[torch] / mineru[full]
parse_server_model_not_readyinvalid_request_error / 400模型未就绪mineru-kit models download --tier standard
not_cached / tier_not_cachedinvalid_request_error / 404读取无缓存且不新建解析先 parse
parse_failedengine_error / 503解析内部异常看日志的阶段计时与告警

公开 Tasks 错误结构只有 error.code / message / param（不输出 type）；内部 CLI/Doclib 异常另有 type 分类。按 HTTP 状态 + code 分支，不要解析 message，也不要把 retryable / user_action 当成现有响应字段。file_parse 使用自己的错误结构。

2. 从现象反推阶段

现象先看常见根因
输出公式为空pdf.inline_vlm 告警切片回退失败；换 ocr 模式复核
表格混乱是否 txt + 原生表格扫描件应走 OCR 档位；看方向检测日志
页数不一致页范围重写日志坏页占位（PageInfo 空块）；源文档损坏
GPU 未使用resolve_small_model_backendTorch 未装或设备不可用 → 回落 ONNX/CPU
内存暴涨窗口大小MINERU_PROCESSING_WINDOW_SIZE 被调大；大页图
首个请求很慢模型加载未 --preload-models；模型首下载
Doclib 读取报错缓存状态list parses 查批次状态与档位
搜索搜不到FTS 更新门槛内容只在质量档位后建索引；flash 片段不足以回答

5. 实战练习

在你自己的环境里执行（环境已就绪：conda mineru + editable 安装）：

  1. 故意拔掉引擎：mineru config set parse_server.local.mode disabled，然后 mineru parse 样例.pdf --json，抄下完整 error 对象，并解释三个字段。
  2. 故意用小窗口：MINERU_PROCESSING_WINDOW_SIZE=8 mineru-kit parse 样例.pdf -o /tmp/x.md，对照日志中的窗口计划行。
  3. 用一个原生文件验证档位边界：mineru-kit parse notes.docx -o notes.md --tier standard，抄下错误码。

把三段输出贴给教师（agent），教师据此记录你的掌握证据。
