4. 什么算“学会”

学习记录只写证据，不写覆盖：“读完第 5 课”不是证据；“能预测第二次 mineru parse 只解析缺失页，并用日志验证”才是。把代码行、命令输出、错误码或对比数据贴给教师（agent），再写入 learning-records/。
  • 概念证据：不看资料复述链路、阶段、边界，并能回答“为什么”。
  • 源码证据：指出具体文件/函数/行，解释其行为。
  • 操作证据：命令输出、日志片段、修复前后对比。
  • 迁移证据：把一个课内结论应用到新文档/新故障上。

6. 卡住时怎么问

  1. 贴出你正在看的文件路径 + 函数名 + 代码行。
  2. 写出你的预期与实际（命令、输出、错误码）。
  3. 说明你已排除的假设（例如“不是 tier 问题，我显式用了 standard”）。
  4. 问一个可回答的问题：“这一行为什么在 VLM 推理期间释放锁？”而不是“讲讲运行时”。
