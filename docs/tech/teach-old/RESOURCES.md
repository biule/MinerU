# MinerU 学习资源

## Knowledge（知识资源）

### 官方文档
- [MinerU 官方文档](https://opendatalab.github.io/MinerU/) — 完整的安装指南、使用教程、API 文档和 FAQ
- [GitHub 仓库](https://github.com/opendatalab/MinerU) — 源码、Issues、讨论
- [MinerU 技术报告 (arXiv)](https://arxiv.org/abs/2409.18839) — 了解 MinerU 的设计思想和 benchmark
- [MinerU2.5 技术报告 (arXiv)](https://arxiv.org/abs/2509.22186) — v2.5 版本技术细节
- [MinerU2.5 Pro 技术报告 (arXiv)](https://arxiv.org/abs/2604.04771) — v2.5 Pro 技术细节

### PDF/文档解析基础
- [PDF Explained (PDF协会)](https://pdfa.org/resource/pdf-explained/) — PDF 格式标准入门
- [PyMuPDF 文档](https://pymupdf.readthedocs.io/) — MinerU 使用的 PDF 底层库之一
- [pypdfium2 文档](https://pypdfium2.readthedocs.io/) — 另一个 PDF 解析底层库

### OCR 相关
- [PaddleOCR 文档](https://github.com/PaddlePaddle/PaddleOCR) — MinerU pipeline 后端使用的 OCR 引擎
- [OmniDocBench 基准](https://github.com/opendatalab/OmniDocBench) — 文档解析领域的标准评测基准
