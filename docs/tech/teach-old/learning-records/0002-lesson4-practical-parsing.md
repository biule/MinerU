# 第 4 课：实战单证解析

用户上完了第 4 课《实战单证解析》，了解了三类单证的特点，用项目 demo PDF 做了实战解析，学习了三个引擎的对比和常见问题排查。

## 关键知识点
- 三类单证的结构差异（发票固定字段、合同多栏文字、报表表格密集）
- `mineru` CLI 的基本用法、`--method` 参数切换引擎
- `--page_range` 调试技巧
- `--parse_method`：auto（自动）、txt（文本）、ocr（OCR 强制）
- 三种引擎的适用场景对比
