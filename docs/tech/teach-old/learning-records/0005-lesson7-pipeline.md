# 第 7 课：搭建单证解析流水线

用户上完了第 7 课《搭建单证解析流水线》，将前 6 课的知识整合为端到端的文档解析流水线。

## 关键知识点
- 流水线六阶段设计模式：收集文件 → 分类判断 → 选择策略 → 调用 MinerU → 提取字段 → 汇总输出
- 用 pypdfium2 提取前几页文字来判断 PDF 是否为扫描件（阈值 < 50 字符）
- 五类文档的策略选择矩阵（文本型/扫描型 × 不同引擎和方法）
- 完整流水线脚本（约 150 行）：自动收集、分类、解析、提取、导出 CSV
- 三种字段提取模式：位置匹配、关键词匹配、结构匹配
- CSV 写入技巧：utf-8-sig 编码保证 Windows Excel 不乱码
- 错误处理思路：单文档失败不中断整体流程
