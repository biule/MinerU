MinerU 术语表

MinerU 文档解析引擎的核心术语定义。所有课程均使用此术语。

核心概念

文档解析
将非结构化或半结构化的文档（PDF、图片、Office 文件）转换为结构化机器可读格式（Markdown、JSON）的过程。
文档转换、文字识别
OCR（光学字符识别）
从图像中识别出文字的技术。用于扫描件、图片类 PDF 的文字提取。
图片转文字
VLM（视觉语言模型）
一种多模态 AI 模型，能同时理解图像和文本。MinerU 使用 VLM 进行高精度文档解析，理解文档的布局和语义。
多模态模型、看图模型
布局分析
识别文档页面中各元素（标题、段落、表格、图片、公式等）的位置和类型，确定它们的阅读顺序。
版面分析
LaTeX
一种专业排版系统，MinerU 使用 LaTeX 格式表示文档中的数学公式。
数学公式代码

架构相关

Pipeline 后端
MinerU 的传统处理引擎，使用专门的深度学习模型（OCR、布局检测等）分步处理文档。资源占用低，可在纯 CPU 上运行。
流水线模式
VLM 后端 (vlm-engine)
基于视觉语言模型的解析引擎，用一个模型同时完成布局分析和文字识别，精度高但需要 GPU。
VLM 模式
Hybrid 后端 (hybrid-engine)
MinerU 默认推荐的混合引擎，同时利用原生文本提取和 VLM 的优势，在速度和精度之间取得平衡。
混合模式
Markdown
MinerU 的主要输出格式，一种轻量级标记语言，用简单符号表示标题、列表、表格、代码等结构。
JSON
MinerU 的可选输出格式，一种结构化的数据交换格式，便于程序进一步处理。

工具与命令

mineru（CLI 命令）
MinerU 的主命令行工具入口，使用 `mineru --help` 查看所有子命令。
mineru-api
MinerU 的 FastAPI 服务，提供 REST API 接口，支持同步和异步任务。
mineru-gradio
MinerU 的图形化 Web 界面，基于 Gradio 框架，适合交互式操作。
Web UI
mineru-router
MinerU 的路由服务，用于多 GPU 多服务的统一入口和任务负载均衡。
负载均衡器

处理流程

parse_method
解析方式的配置参数，可选 auto（自动选择）、txt（强制文本提取）、ocr（强制 OCR）。
effort
Hybrid 后端解析力度参数，可选 medium（快速）或 high（高精度）。
强度、力度
formula_enable
是否启用公式解析，开启后 MinerU 会识别文档中的数学公式并输出为 LaTeX 格式。
公式开关
table_enable
是否启用表格解析，开启后 MinerU 会识别并结构化输出表格为 HTML 格式。
表格开关
